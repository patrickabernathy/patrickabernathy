## 🎓 Teaching & Mentoring

Helping people learn to build software is the part of the job I care about most.

- **Instructor, [Midlands Technical College](https://www.midlandstech.edu/programs-and-courses/science-information-technology-engineering-and-math-stem/ai-enabled-full-stack)** — I teach the **AI-Enabled Full-Stack Developer** training certificate, an evening program for learners with little or no technical background. It runs from HTML and CSS through JavaScript, TypeScript, React / Next.js, APIs, databases, and deployment, with AI-assisted development and Agile / Scrum (PSM I prep) woven throughout. Class is mostly live demos and hands-on labs, and the materials are public:
  - [mtc-ai-developer](https://github.com/patrickabernathy/mtc-ai-developer) — the course hub: setup guides, cheat sheets, and resources for students.
  - [mtc-ai-demos](https://github.com/patrickabernathy/mtc-ai-demos) — every week's demo and lab code, with a `main` starting point and an `answers` branch.
  - I also built an [in-browser practice playground](https://mtc-ai-playground.vercel.app/) (write React / TypeScript, press Run, see it render — no install).
- **Developer enablement & training** — I design structured learning plans and deliver training on agentic coding workflows and context engineering to both technical and business audiences.
